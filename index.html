  2. α = 0.05
  3. เลือกสถิติ σ ไม่ทราบ, n เล็ก, ข้อมูลปกติ → t-test 1 กลุ่ม : t = (X̄ − μ₀)/(s/√n), df = n−1 = 7
  4. คำนวณ X̄ = 388/8 = 48.5 ; s = 2.449 ; s/√n = 2.449/2.828 = 0.866
    t = (48.5 − 50)/0.866 = −1.732 ; p (สองทาง) = 0.127
  5. ตัดสินใจ |t| = 1.732 < t0.025,7 = 2.365 (หรือ p = 0.127 > 0.05) → ยอมรับ H₀
    สรุป: น้ำหนักเฉลี่ยไม่ต่างจาก 50 g อย่างมีนัยสำคัญที่ระดับ 0.05
ลองเปลี่ยนเป็นทางเดียว H₁: μ < 50 (สงสัยว่า “น้อยกว่า”) → p = 0.127 ÷ 2 = 0.063 ยัง > 0.05 ยอมรับ H₀ เหมือนเดิม (นี่คือที่มาของกฎ “หารครึ่ง”)
เชื่อมกับ Type I / II: ถ้าจริง ๆ ขนมเบากว่า 50 g แต่เรายอมรับ H₀ → เกิด Type II (ปล่อยของไม่ครบผ่าน) ซึ่งมักเกิดเมื่อ n น้อย ลองเพิ่ม n ก็ทำให้ตรวจเจอง่ายขึ้น (อำนาจการทดสอบสูงขึ้น)

5.4.1 One-way ANOVA ใช้ทดสอบอะไร?

ใช้ทดสอบค่าเฉลี่ยของประชากร มากกว่า 2 กลุ่ม ที่เป็นอิสระกัน ว่าแตกต่างกันหรือไม่ โดยมีตัวแปรตามเป็นเชิงปริมาณ ตัวแปรอิสระ (กลุ่ม/ปัจจัย) เป็นเชิงจำแนก 1 ตัว
H₀: μ₁ = μ₂ = μ₃ = … = μk
H₁: มี μi อย่างน้อย 2 ค่าที่ไม่เท่ากัน

สถิติทดสอบ: F = MSTr / MSE ~ F(k−1, n−k)  |  ปฏิเสธ H₀ ถ้า p ≤ α หรือ F ≥ fα,(k−1,n−k)

ข้อตกลงเบื้องต้น

  • ตัวอย่างแต่ละกลุ่มสุ่มมาอย่างอิสระ

  • ประชากรทุกกลุ่มความแปรปรวนเท่ากัน (เช็กด้วย Levene)

5.4.2 การเปรียบเทียบพหุคูณ (Multiple Comparison) – หาคู่ที่แตกต่าง

ทำเมื่อไร? ทำหลัง ANOVA ปฏิเสธ H₀ เท่านั้น (ถ้ายอมรับ H₀ ก็จบ ไม่ต้องหาคู่)
สมมติฐานของแต่ละคู่: H₀: μi = μj   H₁: μi ≠ μj   → ดู Sig. ของคู่นั้น ปฏิเสธถ้า p ≤ α
วิธีลักษณะ / เงื่อนไขใช้
LSD (Least Significant Difference)เปรียบเทียบค่าเฉลี่ยได้ครั้งละหลายคู่ (คำนวณมือง่าย)
Tukey's HSDตัวอย่างแต่ละกลุ่มมีขนาดเท่ากัน
Schefféขนาดตัวอย่างแต่ละกลุ่มเท่ากันหรือไม่เท่ากันก็ได้
Bonferroniจำนวนกลุ่มไม่เกิน 5 กลุ่ม

วิธี LSD (คิดมือ)

  1. คำนวณ LSD = tα/2, ν · √[ MSE (1/ni + 1/nj) ] เมื่อ ν = n − k และ MSE ได้จากตาราง ANOVA
  2. หาผลต่างของค่าเฉลี่ยทุกคู่ |X̄i − X̄j|
  3. ถ้า |X̄i − X̄j| ≥ LSD → คู่นั้นแตกต่างอย่างมีนัยสำคัญ ; ถ้า < LSD → ไม่แตกต่าง

1) One-Sample Wilcoxon Signed Rank Test

  1. H₀: M = M₀ ; H₁: M ≠ M₀ (หรือ > , <) ; กำหนด α
  2. คำนวณ Di = Xi − M₀ ; ตัดค่า Di = 0 ทิ้ง (n นับเฉพาะที่ไม่ใช่ 0)
  3. จัดอันดับ |Di| จากน้อยไปมาก (ค่าเท่ากันใช้อันดับเฉลี่ย) แล้วใส่เครื่องหมายตาม Di
  4. T⁺ = ผลรวมอันดับที่เป็น +, T⁻ = ผลรวมอันดับที่เป็น −
  5. สถิติ: สองทาง T = min(T⁻, T⁺) ; H₁: M > M₀ ใช้ T⁻ ; H₁: M < M₀ ใช้ T⁺
  6. ปฏิเสธ H₀ ถ้า T ≤ Tวิกฤต (ตาราง Wilcoxon, n ≤ 30) หรือ p ≤ α
n > 30 ใช้ประมาณปกติ: Z = (T − μT)/σT เมื่อ μT = n(n+1)/4 , σ²T = n(n+1)(2n+1)/24 (ถ้ามีค่าซ้ำต้องปรับความแปรปรวน)
📌 ตัวอย่างท่อเหล็ก (H₀: M = 10 นิ้ว) ข้อมูล: 9, 10, 11, 9, 10, 9, 9, 9, 8, 9 → D = −1, 0, +1, −1, 0, −1, −1, −1, −2, −1
ตัด 0 ทิ้ง 2 ค่า → n = 8 · |D| = 1 มี 7 ตัว (อันดับเฉลี่ย 4) · |D| = 2 ได้อันดับ 8
T⁺ = 4 · T⁻ = 4×6 + 8 = 32 → T = 4 · ตาราง: 2P(T ≤ 4) = 2(0.0273) = 0.0546 > 0.05 → ยอมรับ H₀ มัธยฐาน = 10 นิ้ว
📌 SPSS: คะแนนความเครียด vs 22.74 Analyze → Nonparametric Tests → One Sample → Settings: “Compare median to hypothesized (Wilcoxon signed-rank)” ใส่ M₀ = 22.74
p < 0.001 → ปฏิเสธ H₀ → มัธยฐานคะแนนความเครียดต่างจากรายงานเดิม

2) Mann–Whitney U Test

  1. H₀: M₁ = M₂ ; H₁: M₁ ≠ M₂ (หรือ > , <) ; กำหนด α
  2. รวมตัวอย่างทั้ง 2 กลุ่ม (n = n₁ + n₂) เรียงอันดับ 1 ถึง n (ค่าซ้ำใช้อันดับเฉลี่ย)
  3. หาผลรวมอันดับของแต่ละกลุ่ม T₁, T₂
  4. U₁ = n₁n₂ + n₁(n₁+1)/2 − T₁
    U₂ = n₁n₂ + n₂(n₂+1)/2 − T₂
    U = min(U₁, U₂)   (ตรวจสอบ: U₁ + U₂ = n₁n₂)
  5. ปฏิเสธ H₀ ถ้า U ≤ U₀ (ตาราง Mann–Whitney) หรือ p ≤ α ; ถ้า n₁, n₂ > 20 ประมาณด้วย Z
📌 ตัวอย่างคะแนน Online vs ห้องเรียน กลุ่ม 1 (n₁=7): 130 135 138 144 148 155 168 → อันดับ 1,2,3,5,7,9,12 → T₁ = 39
กลุ่ม 2 (n₂=9) → T₂ = 136 − 39 = 97
U₁ = 63 + 28 − 39 = 52 · U₂ = 63 + 45 − 97 = 11 · U = 11 ; U₀ = 12 → 11 < 12 → ปฏิเสธ H₀ ประสิทธิภาพการเรียนรู้ต่างกัน
📌 SPSS: ความเครียดชาย vs หญิง Analyze → Nonparametric Tests → Independent Samples (ตัวแปรเพศไปช่อง Groups) · Settings: Mann–Whitney U (2 samples)
p = 0.828 > 0.05 → ยอมรับ H₀ → มัธยฐานความเครียดชายกับหญิงไม่แตกต่างกัน

3) Wilcoxon Signed-Rank Test (Matched-Pair)

  1. H₀: Mก่อน = Mหลัง ; H₁: ≠ (หรือ > , <) ; กำหนด α
  2. หา di = ก่อน − หลัง แต่ละคู่ · ตัดคู่ที่ di = 0 ทิ้ง
  3. จัดอันดับ |di| (ค่าซ้ำใช้อันดับเฉลี่ย) แล้วใส่เครื่องหมายตาม di → หา T⁺, T⁻
  4. n = จำนวนคู่ที่ d ≠ 0 ; T = min(T⁺, T⁻)
  5. ปฏิเสธ H₀ ถ้า T ≤ T₀ (ตาราง Wilcoxon) หรือ p ≤ α

H₁: Mก่อน > Mหลัง · p < 0.001 → ปฏิเสธ H₀ → โปรแกรมลดความเครียดได้ผล (ใช้เมื่อกลุ่ม “หลัง” ไม่ปกติ จึงไม่ใช้ Paired t)

4) Kruskal–Wallis Test

  1. H₀: M₁ = M₂ = … = Mk ; H₁: อย่างน้อย 2 ค่าไม่เท่ากัน ; กำหนด α
  2. รวมทุกกลุ่ม (n = n₁ + … + nk) เรียงอันดับ 1 ถึง n
  3. หาผลรวมอันดับของแต่ละกลุ่ม Ri
  4. KW = [12 / n(n+1)] · Σ (Ri² / ni) − 3(n+1)
  5. ปฏิเสธ H₀ ถ้า KW ≥ KWα (ตาราง Kruskal–Wallis หรือ χ²α, k−1) หรือ p ≤ α
📌 ตัวอย่างมโนทัศน์ ครู / ผู้บริหาร / ศึกษานิเทศก์ n₁ = 5, n₂ = 5, n₃ = 4, n = 14 · R₁ = 22, R₂ = 37, R₃ = 46 (รวม 105 ✔)

A) การวิเคราะห์สหสัมพันธ์ (Correlation)

สหสัมพันธ์ = ศึกษาความสัมพันธ์เชิงเส้นตรงระหว่างตัวแปรต่อเนื่องตั้งแต่ 2 ตัว · ค่าสัมประสิทธิ์สหสัมพันธ์ r (ตัวอย่าง) / ρ (ประชากร) บอกขนาดและทิศทาง
2 ตัว = simple correlation · > 2 ตัว = multiple correlation
r = Σ(X−X̄)(Y−Ȳ) / √[Σ(X−X̄)² · Σ(Y−Ȳ)²] = [ΣXY − (ΣX)(ΣY)/n] / √{[ΣX² − (ΣX)²/n][ΣY² − (ΣY)²/n]}
−1 ≤ r ≤ +1
ค่า rความหมาย
r > 0ทิศทางเดียวกัน (แปรผันตาม)
r < 0ทิศทางตรงข้าม (แปรผกผัน)
r = +1 / −1สัมพันธ์สมบูรณ์ทิศเดียวกัน / ตรงข้าม
r = 0ไม่มีความสัมพันธ์เชิงเส้น
|r|ระดับ (Hinkle et al.)
0.90 – 1.00สูงมาก (Very high)
0.70 – 0.90สูง (High)
0.50 – 0.70ปานกลาง (Moderate)
0.30 – 0.50ต่ำ (Low)
0.00 – 0.30น้อยมาก (Negligible)

การทดสอบสมมติฐานเกี่ยวกับ ρ

  1. H₀: ρ = 0 (ไม่มีความสัมพันธ์) ; H₁: ρ ≠ 0 (มีความสัมพันธ์) [ทางเดียว: ρ > 0 หรือ ρ < 0 ได้]
  2. กำหนด α = 0.05
  3. สถิติ ถ้า ρ₀ = 0: T = r·√(n−2) / √(1−r²) , df = n − 2
    ถ้า ρ₀ ≠ 0: Z = [√(n−3)/2] · ln{ (1+r)(1−ρ₀) / [(1−r)(1+ρ₀)] }
  4. หา p-value (SPSS: Analyze → Correlate → Bivariate, ติ๊ก Pearson, Two-tailed)
  5. ปฏิเสธ H₀ ถ้า p ≤ α แล้วสรุป พร้อมบอกทิศทาง(เครื่องหมาย r)และระดับ(ขนาด |r|)
📌 ตัวอย่างคิดมือ: รายได้ (X) กับค่าอาหาร (Y) 10 ครัวเรือน ΣX = 60, ΣY = 180, ΣX² = 406, ΣY² = 3,396, ΣXY = 1,159
r = (1,159 − 60·180/10) / √[(406 − 60²/10)(3,396 − 180²/10)] = 79 / 84.71 = 0.9326
t = 0.9326·√(8/(1−0.9326²)) = 7.309 , df = 8 → p = 8.3×10⁻⁵ < 0.05 → ปฏิเสธ H₀
→ รายได้มีความสัมพันธ์ทางบวกสูงมากกับค่าใช้จ่ายด้านอาหาร
📌 ตัวอย่าง SPSS: คะแนนความรู้ vs ความเครียด (n = 150) Pearson r = .073 , Sig. (2-tailed) = .372 > 0.05 → ยอมรับ H₀ → ไม่มีความสัมพันธ์ (p > 0.05)
(ถ้าได้ r = .734 , Sig. = .003 จะสรุปว่า มีความสัมพันธ์ทิศเดียวกัน ระดับสูง; ถ้า r = −.734 คือ ทิศตรงข้าม ระดับสูง)

B) การถดถอยเชิงเส้น (Linear Regression)

เป็นวิธีศึกษารูปแบบความสัมพันธ์ระหว่าง ตัวแปรตาม (Y) กับ ตัวแปรอิสระ (X) เพื่อ ① ดูระดับ/ทิศทางที่ X แต่ละตัวมีผลต่อ Y ② สร้างสมการเพื่อทำนาย Y
X ตัวเดียว = simple regression · X มากกว่า 1 ตัว = multiple regression

⭐ ตัวแบบประชากร vs ตัวแบบตัวอย่าง

ตัวแบบของประชากรตัวแบบของตัวอย่าง
สมการ (simple)Y = β₀ + β₁X + εŶ = b₀ + b₁X
สมการ (multiple)Y = β₀ + β₁X₁ + … + βkXk + εŶ = b₀ + b₁X₁ + … + bkXk
สัมประสิทธิ์β = พารามิเตอร์ (ค่าจริงที่ไม่ทราบ)b = ตัวประมาณของ β (คำนวณจากข้อมูล)
ความคลาดเคลื่อนมี ε (ตัวแปรสุ่ม)ไม่มี ε (ได้ค่าทำนาย Ŷ ซึ่ง Y − Ŷ = ส่วนเหลือ/residual)
  • β₀ (b₀) = ค่าของ Y เมื่อ X = 0 (จุดตัดแกน Y)
  • β₁ (b₁) = ความชัน: X เพิ่ม 1 หน่วย → Y เปลี่ยนไป b₁ หน่วย · β₁ > 0 ทิศเดียวกัน, < 0 ทิศตรงข้าม, = 0 ไม่มีความสัมพันธ์เชิงเส้น
  • Multiple: bi = การเปลี่ยนของ Y เมื่อ Xi เพิ่ม 1 หน่วย โดยกำหนดให้ X อื่นคงที่ (partial regression coefficient)
ข้อสมมติของ ε: แจกแจงปกติ · เป็นอิสระต่อกัน · ค่าเฉลี่ย = 0 · ความแปรปรวนคงที่  (+ multiple: ตัวแปรอิสระไม่สัมพันธ์กันเอง)

🛠 การสร้างตัวแบบถดถอย (ลำดับงาน)

  1. เตรียมข้อมูล X, Y – ดู Scatter plot / Correlation ว่ามีแนวโน้มเชิงเส้นไหม
  2. ทดสอบสมมติฐาน – F-test (ภาพรวมตัวแบบ) และ t-test (แต่ละ b)
  3. สร้างสมการ Ŷ = b₀ + b₁X₁ + …
  4. ตรวจความเหมาะสม – R², Adjusted R² และตรวจข้อตกลงเบื้องต้น
การทดสอบH₀H₁สถิติตอบคำถาม
F-test (ANOVA)β₁ = β₂ = … = βk = 0มี βi อย่างน้อย 1 ตัว ≠ 0F = MSTr/MSE ~ F(k−1, n−k)มีตัวแปรอิสระ อย่างน้อย 1 ตัว ที่อธิบาย Y ได้ไหม (ตัวแบบใช้ได้ไหม)
t-test สำหรับ β₁β₁ = 0β₁ ≠ 0T = (b − β)/Sb , df = n−2X กับ Y สัมพันธ์กันไหม (ตัวแปรนี้ควรอยู่ในสมการไหม)
t-test สำหรับ β₀β₀ = 0β₀ ≠ 0T = (b₀ − β₀)/Sa , df = n−2จุดตัดแกน Y เป็น 0 ไหม

วิธีคิดให้เป็นลำดับ: ① ตัวแปรตามเป็นชนิดไหน (ปริมาณ / คุณภาพ) → ② กี่กลุ่ม / กี่ตัวแปร → ③ อิสระหรือจับคู่ → ④ ปกติไหม

1) วัดความดันของคนไข้ 20 คน ก่อน-หลังกินยา ข้อมูลปกติ
ปริมาณ + 2 กลุ่ม + จับคู่ + ปกติ → Paired t-test (ถ้าไม่ปกติ → Wilcoxon Matched-Pair)
2) เทียบรายได้ของพนักงาน 4 แผนก (ไม่ปกติ)
ปริมาณ + 4 กลุ่มอิสระ + ไม่ปกติ → Kruskal–Wallis (ถ้าปกติ → One-way ANOVA)
3) สุ่มคนมา 200 คน ถามเพศ และยี่ห้อมือถือที่ใช้ ว่าสัมพันธ์กันไหม
คุณภาพ 2 ตัว จากกลุ่มเดียว → χ² Independence
4) สุ่มนักเรียนแยก 3 โรงเรียน เทียบสัดส่วนคนที่สอบผ่านว่าเท่ากันไหม
สุ่มแยกหลายประชากร เทียบสัดส่วน → χ² Homogeneity
5) ต้องการประมาณยอดขาย (Y) จากงบโฆษณาและจำนวนสาขา
ทำนาย Y จาก X 2 ตัว → Multiple linear regression (ตรวจ Tolerance/VIF ด้วย)
6) เปรียบเทียบคะแนนความพอใจ (1–5) ของลูกค้า 2 สาขา ข้อมูลเป็นอันดับ ไม่ปกติ
2 กลุ่มอิสระ + อันดับ → Mann–Whitney U
🌸 ทำจากสไลด์บท 5, 6, 7 ของ อ.ดร.ธนวรรณ · ขอให้สอบผ่านสวย ๆ นะคะ ✨
